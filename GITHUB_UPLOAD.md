# GitHub Upload — PropertyBazaar (Gujarati)

## Method 1: Website thi (saru — beginner mate)

### 1. Account
- https://github.com/signup → free account banao
- Email verify karo

### 2. Navo repo
- https://github.com/new
- **Repository name:** `propertybazaar`
- **Public** select karo
- **Add a README file** — UNCHECK (khali repo)
- **Create repository**

### 3. Files upload
- Repo page par **"uploading an existing file"** link click karo
- Windows Explorer ma folder kholo:
  `PropertyBazaar_Pytn - Copy`
- **Badhi files/folders** select kari drag-drop karo GitHub page par  
  **VAGAR RAKHO (upload NATHI):**
  - `venv` (folder)
  - `.env` (file)
  - `db.sqlite3`
  - `media` (folder)
  - `staticfiles` (folder)
  - `__pycache__` (folders)
  - `.git` (folder — jo dekhaay to skip)

### 4. Commit
- Nichhe message: `Initial upload`
- **Commit changes** → pachhi **Commit to main** (jo puchhe)

### 5. Check
- Repo ma `render.yaml`, `manage.py`, `apps` folder dekhaay = success
- URL: `https://github.com/TAMARU_USERNAME/propertybazaar`

## Method 2: ZIP upload (jo drag-drop fail thay)

1. Folder ma jao, `venv`, `.env`, `db.sqlite3`, `media`, `staticfiles` delete/copy **vagar** badha select
2. Right-click → **Compress to ZIP**
3. https://github.com/new → repo `propertybazaar`
4. GitHub Desktop install: https://desktop.github.com  
   OR use Method 1 drag-drop for folders
